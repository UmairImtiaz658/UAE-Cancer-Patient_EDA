# UAE-Cancer-Patient_EDA
This project delivers a **professional-grade exploratory data analysis (EDA)** on cancer patient data from the UAE, reflecting how data scientists analyze sensitive healthcare datasets before modeling or policy decisions.

✔ Strong healthcare & government relevance  
✔ Structured EDA storytelling  
✔ Insight-driven visual analysis  
✔ Public health & decision-support focus  
✔ Recruiter-ready presentation  

---

## 📌 Problem Statement
Cancer is a major public health concern worldwide. Understanding patient demographics, cancer types, and treatment patterns is essential for **policy planning, hospital resource allocation, and preventive strategies**.

> **Goal:** Perform in-depth exploratory analysis to uncover meaningful insights from UAE cancer patient data.

---

## 🧠 Analysis Overview
This project answers key healthcare questions:
- Which cancer types are most prevalent?
- How does cancer distribution vary by age and gender?
- What patterns exist across regions and patient categories?
- What insights can support healthcare decision-makers?

---

## 🗂 Dataset Information
- **Dataset:** UAE Cancer Patient Dataset
- **Type:** Structured healthcare data
- **Region:** United Arab Emirates
- **Nature:** Observational / Public health data

### 🔑 Key Attributes
- Patient Age
- Gender
- Cancer Type
- Nationality / Region
- Treatment Category
- Year / Diagnosis Information

---

## 🔬 Exploratory Data Analysis (EDA)
Key EDA steps performed:
- Data quality checks (missing values, duplicates)
- Descriptive statistics
- Age and gender distribution analysis
- Cancer-type frequency analysis
- Visualizations using bar charts, histograms, and count plots

> EDA transforms raw data into **actionable healthcare insights**.

---

## 📊 Key Insights
- Identification of high-risk age groups
- Most common cancer types in the UAE
- Gender-based cancer prevalence patterns
- Data-backed insights useful for policy and hospital planning
